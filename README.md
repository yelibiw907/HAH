## معرفی

**Hadi Panel** یک پنل مدیریت VPN کاملاً رایگان روی Cloudflare Workers است که:

- به عنوان سرور **VLESS** (روی WebSocket + TLS) عمل می‌کند
- یک **داشبورد مدیریت وب** با طراحی حرفه‌ای دارد
- قابلیت مدیریت چند کاربر با محدودیت حجم، زمان، و تعداد اتصال
- کاملاً روی پلن **Free** کلودفلر کار می‌کند
- با اپلیکیشن‌های **v2rayNG**, **NekoBox**, **Streisand**, **FoXray** و مشابه سازگار است

## نصب و راه‌اندازی

### ۱. نصب Wrangler

```bash
npm install -g wrangler
wrangler login
```

### ۲. دانلود پروژه

فایل `HAH-features.zip` را دانلود و اکسترact کنید:

```bash
unzip HAH-features.zip
cd HAH-features
```

### ۳. ساخت KV Namespace

```bash
wrangler kv namespace create VLESS_USERS
```

خروجی یک `id` می‌دهد. آن را در `wrangler.toml` جایگزین کنید:

```toml
[[kv_namespaces]]
binding = "VLESS_USERS"
id = "جاگزین_کنید"
```

### ۴. تنظیم Secret‌ها

```bash
# رمز عبور مدیر (الزامی)
wrangler secret put ADMIN_PASSWORD

# آمار Cloudflare (اختیاری - برای نمایش آمار ریکوئست)
wrangler secret put CF_API_TOKEN
wrangler secret put CF_ACCOUNT_ID

# ربات تلگرام (اختیاری)
wrangler secret put BOT_TOKEN
wrangler secret put BOT_CHAT_ID

# وب‌هوک (اختیاری)
wrangler secret put WEBHOOK_URL
```

### ۵. دیپلوی

```bash
wrangler deploy
```

### ۶. وصل کردن دامنه (اختیاری ولی پیشنهادی)

از پنل Cloudflare → Workers & Pages → پروژه شما → Triggers → Custom Domains، یک دامنه اضافه کنید.

مثال: `vpn.example.com`

> **نکته:** دامنه اختصاصی گواهی TLS معتبر و SNI درست می‌دهد که برای اتصال کلاینت‌های VLESS لازم است.

## ساختار فایل‌ها

```
HAH-features/
├── wrangler.toml          # تنظیمات دیپلوی + KV + Secrets
├── worker.js              # بک‌اند: VLESS proxy + API مدیریت
└── public/
    └── index.html         # فرانت‌اند: داشبورد مدیریت
```

### wrangler.toml

تنظیمات Cloudflare Workers شامل:
- نام Worker
- بایندینگ KV (پایگاه داده کاربران)
- بایندینگ Assets (فایل‌های استاتیک)
- Environment Variables

### worker.js

بک‌اند پنل شامل:
- **پروکسی VLESS:** `parseVlessHeader()`, `handleVlessConnection()`
- **مدیریت کاربران:** CRUD کامل + محدودیت‌ها
- **آمار:** Cloudflare Analytics API + آمار داخلی
- **امنیت:** احراز هویت + Rate Limiting + 2FA
- **اعلان‌ها:** تلگرام + وب‌هوک
- **لاگ:** فعالیت کاربران + اتصالات

### public/index.html

داشبورد مدیریت (فایل واحد شامل CSS + JS):
- طراحی حرفه‌ای مشکی-طلایی
- پشتیبانی RTL (راست به چپ)
- فونت Vazirmatn + JetBrains Mono
- آیکون‌های Font Awesome
- نمودارها و چارت‌ها (SVG)

## تنظیم Secret‌ها

| Secret | توضیح | الزامی |
|--------|-------|--------|
| `ADMIN_PASSWORD` | رمز عبور ورود به پنل | ✅ بله |
| `CF_API_TOKEN` | توکن API کلودفلر (برای آمار ریکوئست) | ❌ خیر |
| `CF_ACCOUNT_ID` | آیدی اکانت کلودفلر | ❌ خیر |
| `BOT_TOKEN` | توکن ربات تلگرام (از @BotFather) | ❌ خیر |
| `BOT_CHAT_ID` | آیدی چت تلگرام (برای ارسال اعلان) | ❌ خیر |
| `WEBHOOK_URL` | آدرس webhook (Discord/Slack/...) | ❌ خیر |

### ساخت ربات تلگرام

1. به @BotFather در تلگرام بروید
2. دستور `/newbot` را بزنید
3. نام ربات را وارد کنید
4. توکن دریافتی را به عنوان `BOT_TOKEN` تنظیم کنید
5. آیدی چت مدیر را به عنوان `BOT_CHAT_ID` تنظیم کنید

> **نکته:** برای دریافت آیدی چت، ربات @userinfobot را استفاده کنید.

## استفاده از داشبورد

### ورود

1. به آدرس Worker خود بروید (مثلاً `https://vpn.example.com/`)
2. رمز عبور مدیر را وارد کنید
3. اگر 2FA فعال باشد، کد TOTP را وارد کنید

### افزودن کاربر

1. به بخش **کلاینت‌ها** بروید
2. روی **افزودن کاربر** کلیک کنید
3. اطلاعات را پر کنید:
   - **نام:** نام کاربر
   - **سقف ترافیک (GB):** ۰ = نامحدود
   - **محدودیت ریکوئست روزانه:** ۰ = نامحدود
   - **تاریخ انقضا:** خالی = نامحدود
   - **حداکثر اتصال همزمان:** ۰ = نامحدود
   - **سرعت دانلود (MB/s):** ۰ = نامحدود
   - **سرعت آپلود (MB/s):** ۰ = نامحدود
   - **لیست سفید IP:** آدرس‌های IP مجاز (جدا شده با کاما)
   - **لیست سیاه IP:** آدرس‌های IP ممنوع (جدا شده با کاما)

### اتصال کاربر

1. لینک `vless://...` یا لینک سابسکرایشن `/sub/<uuid>` را کپی کنید
2. در اپلیکیشن VPN (v2rayNG, NekoBox, Streisand, FoXray) وارد کنید
3. یا کد QR را اسکن کنید

```bash
  "uploadSpeedMBps": 5,

# حذف کاربر

# بازنشانی ترافیک
PUT /api/users/:uuid/reset-traffic

# بازنشانی ریکوئست
PUT /api/users/:uuid/reset-requests
```

## ویژگی‌های جدید v4

### ۱. غیرفعال‌سازی خودکار منقضی

هر ساعت، کاربرانی که تاریخ انقضای آن‌ها گذشته باشد به صورت خودکار غیرفعال می‌شوند. این بررسی هنگام لود داشبورد انجام می‌شود (حداکثر یک بار در ساعت).

### ۲. هشدار ترافیک

وقتی مصرف ترافیک کاربر به ۸۰٪ یا ۹۰٪ سقف برسد، یک هشدار در سیستم لاگ ثبت می‌شود. این هشدارها در بخش اعلان‌های داشبورد نمایش داده می‌شوند.

### ۳. محدودیت اتصال همزمان

برای هر کاربر می‌توان حداکثر تعداد اتصال همزمان را تعیین کرد (۰ = نامحدود). اتصال‌های فعال در KV ردیابی می‌شوند و اتصال اضافی رد می‌شود.

### ۴. محدودیت پهنای باند

می‌توان سرعت دانلود و آپلود هر کاربر را به صورت مگابایت بر ثانیه محدود کرد. در صورت تجاوز از سقف، انتقال داده با تأخیر انجام می‌شود.

### ۵. ربات تلگرام

با تنظیم `BOT_TOKEN` و `BOT_CHAT_ID`، اعلان‌های زیر به تلگرام ارسال می‌شوند:
- ایجاد کاربر جدید
- حذف کاربر
- منقضی شدن اشتراک
- هشدار ترافیک

همچنین دکمه «ارسال خلاصه به تلگرام» در تنظیمات موجود است.

### ۶. وب‌هوک

با تنظیم `WEBHOOK_URL`، رویدادها به صورت POST JSON به آدرس مشخص‌شده ارسال می‌شوند. مناسب برای اتصال به Discord, Slack, یا سرویس‌های دیگر.

### ۷. لاگ اتصالات

برای هر اتصال VLESS، اطلاعات زیر ذخیره می‌شود:
- آدرس IP مقصد
- پورت مقصد
- حجم داده رد و بدل شده
- زمان اتصال

حداکثر ۵۰ رکورد اخیر برای هر کاربر نگهداری می‌شود.

### ۸. خروجی CSV

امکان دانلود لیست کاربران به صورت فایل CSV (سازگار با اکسل) با ستون‌های:
نام، UUID، ترافیک مصرفی، سقف ترافیک، انقضا، وضعیت، ریکوئست امروز

### ۹. نمودار پهنای باند

مصرف پهنای باند هر ۵ دقیقه نمونه‌برداری شده و به مدت ۳ روز نگهداری می‌شود. نمودار ۲۴ ساعت گذشته در داشبورد نمایش داده می‌شود.

### ۱۰. لیست سفید/سیاه IP

برای هر کاربر می‌توان:
- **لیست سفید:** فقط IPهای مشخص‌شده اجازه اتصال دارند
- **لیست سیاه:** IPهای مشخص‌شده مجاز به اتصال نیستند

### ۱۱. احراز هویت دو مرحله‌ای (2FA)

پشتیبانی از TOTP (Google Authenticator, Authy, ...) بدون نیاز به کتابخانه خارجی. کد QR برای اضافه کردن به اپلیکیشن احراز هویت نمایش داده می‌شود.

### ۱۲. صفحه سابسکرایشن اختصاصی

قالب صفحه اطلاعات اشتراک (که کاربر با باز کردن لینک سابسکرایشن در مرورگر می‌بیند) قابل ویرایش است. از بخش تنظیمات → قالب سابسکرایشن قابل دسترسی است.

### ۱۳. چند زبانه

پنل از فارسی (پیش‌فرض) و انگلیسی پشتیبانی می‌کند. زبان از طریق دکمه در هدر قابل تغییر است و در localStorage ذخیره می‌شود.

### ۱۴. حالت روشن/تاریک

حالت پیش‌فرض مشکی است. با کلیک روی آیکون ماه/خورشید در هدر، می‌توان بین حالت روشن و تاریک جابجا شد. ترجیح در localStorage ذخیره می‌شود.

## نکات مهم و محدودیت‌ها

### محدودیت‌های Cloudflare Workers

| مورد | محدودیت پلن رایگان |
|------|---------------------|
| CPU Time | ۱۰ میلی‌ثانیه درخواست |
| KV Read | ۱۰۰,۰۰۰ درخواست/روز |
| KV Write | ۱,۰۰۰ درخواست/روز |
| KV Storage | ۱ گیگابایت |
| Inbound Traffic | نامحدود |
| Outbound Traffic | نامحدود |

### نکات مهم

- **شمارش ترافیک:** به دلیل محدودیت نرخ نوشتن KV، مصرف هر اتصال هر ۳۰ ثانیه یک‌بار ذخیره می‌شود (یا وقتی ۸ مگابایت رد و بدل شود). برای تعداد کم کاربر کاملاً کافی است.

- **پروتکل:** فقط TCP پشتیبانی می‌شود. UDP (مثل برخی بازی‌ها) پشتیبانی نمی‌شود.

- **امنیت پنل:** رمز مدیر را قوی انتخاب کنید. نشست ورود ۱۲ ساعت معتبر است. استفاده از 2FA بشدت پیشنهاد می‌شود.

- **دامنه:** استفاده از دامنه اختصاصی (نه workers.dev) برای عملکرد بهتر و عبور از فیلترینگ ضروری است.

- **قوانین محلی:** مسئولیت استفاده از این ابزار و رعایت قوانین کشور خودتان بر عهده خودتان است.

## عیب‌یابی

### مشکل: کاربر نمی‌تواند وصل شود

1. مطمئن شوید Worker دیپلوی شده: `wrangler deploy`
2. مطمئن شوید دامنه وصل است و TLS فعال است
3. بررسی کنید کاربر فعال باشد (غیرفعال نباشد)
4. بررسی کنید تاریخ انقضا نگذشته باشد
5. بررسی کنید ترافیک تمام نشده باشد
6. بررسی کنید IP کاربر در لیست سیاه نباشد

### مشکل: داشبورد لود نمی‌شود

1. آدرس URL را بررسی کنید (باید https باشد)
2. کش مرورگر را پاک کنید
3. رمز عبور را بررسی کنید

### مشکل: آمار نمایش داده نمی‌شود

1. `CF_API_TOKEN` و `CF_ACCOUNT_ID` را تنظیم کنید
2. مطمئن شوید توکن دسترسی Workers Analytics دارد

### مشکل: تلگرام کار نمی‌کند

1. توکن ربات را بررسی کنید: `wrangler secret put BOT_TOKEN`
2. آیدی چت را بررسی کنید: `wrangler secret put BOT_CHAT_ID`
3. مطمئن شوید ربات در چت عضو است
